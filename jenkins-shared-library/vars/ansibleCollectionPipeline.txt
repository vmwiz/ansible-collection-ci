ansibleCollectionPipeline(Map config) - pipeline declaratif complet pour une collection Ansible (airgap, Nexus).

Jenkinsfile minimal :
    @Library('ansible-ci@v1') _
    ansibleCollectionPipeline()

Exemple :
    ansibleCollectionPipeline(ansibleCoreOptional: ['2.20'], integration: true,
                              spotter: true, spotterEndpoint: 'https://spotter.corp.local/api')
    ansibleCollectionPipeline(targetEEs: ['hub.corp.local/ansible-automation-platform-26/ee-minimal-rhel9:latest'])

Etapes : Configuration > EE cibles (si targetEEs) > Controles statiques (Changelog PR, Certification Red Hat, Lint,
       Docs, Build + galaxy-importer, Securite, Spotter, en parallele) > ansible-test sanity/units (une branche
       parallele par serie + sanity de certification manquantes) > EE units (POC) > Integration > Molecule > Publication (tag).

Parametres (defaut) - toute cle inconnue ou valeur invalide arrete le build avec la liste des erreurs :
  Matrice
    ansibleCoreVersions    ['2.16','2.18']  series testees (chaines !) = AAP 2.6
    ansibleCoreOptional    []         series en plus, NON bloquantes (echec -> UNSTABLE), ex. ['2.20'] = AAP 2.7
    ansibleCorePrerelease  []         series en pre-version : ansible-core>=X.Y.0a0,<X.Y+1 ; echec -> UNSTABLE
    targetEEs              []         images EE cibles : matrice derivee par introspection (exclusif avec
                                      ansibleCoreVersions) ; echec immediat si requires_ansible/Python incompatibles
    ansibleCoreDefault     null       serie des etapes non matricielles (defaut : derniere serie non pre-version)
    pythonMap              [:]        surcharge de la table serie -> Pythons controleur, ex. ['2.23': ['3.15']]
    prereleaseUnstable     true       echec d'une pre-version = UNSTABLE au lieu de FAILURE
  Etapes (true/false)
    lint docs build galaxyImporter securityScan sanity units publish : true
    certification          true       controles certification Red Hat (voir ansibleCertification.txt)
    certificationSanity    true       sanity Python 3.12 sur stable-2.16/2.18/2.20 (filtrees par requires_ansible)
    changelogCheck         true       fragment changelog obligatoire sur PR (job multibranche)
    changelogSkipToken     'skip-changelog'
    eeTests                false      POC : units dans les EE (exige targetEEs ; non teste)
    spotter integration molecule : false            publish ne s'execute que sur un tag
  ansible-test

    moleculeImages         ['ubuntu2404','fedora40']

    dockerNetwork          ''         --docker-network
    coverage               false      --coverage + rapport XML
    failFast               false      arrete les autres branches au premier echec
